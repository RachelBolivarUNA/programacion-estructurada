# Skill Builder 02

## Variables & Data Types

> "Programming is a skill. Skills are built through practice."

---

## Objective

Reforzar los conceptos aprendidos en el Chapter 02 mediante ejercicios prácticos.

Esta práctica **no tiene calificación**.

Su propósito es ayudarte a ganar fluidez programando y prepararte para el siguiente capítulo.

---

## Concepts Covered

Al finalizar este Skill Builder deberías sentirte cómodo con:

- Variables
- Tipos de datos
- `cin`
- `cout`
- Declaración de variables
- Mostrar información en pantalla
- Leer información del usuario

---

## Practice Exercises

### Exercise 01 — Say "Hello, World!" With C++

**Objetivo:** Verificar que puedes compilar y ejecutar correctamente un programa en C++.

**Plataforma:** HackerRank

**Link:** https://www.hackerrank.com/challenges/cpp-hello-world/problem

### Exercise 02 — Input and Output

**Objetivo:** Practicar la entrada y salida de datos utilizando `cin` y `cout`.

**Plataforma:** HackerRank

**Link:** https://www.hackerrank.com/challenges/cpp-input-and-output/problem

### Exercise 03 — Basic Data Types

**Objetivo:** Practicar el uso de distintos tipos de datos.

**Plataforma:** HackerRank

**Link:** https://www.hackerrank.com/challenges/c-tutorial-basic-data-types/problem

---

## Important

En algunos ejercicios HackerRank utiliza `scanf` y `printf`.

Durante este curso debes resolverlos utilizando únicamente:

- `cin`
- `cout`

Aunque el resultado sea el mismo.

## Bonus Challenge

Modifica el laboratorio realizado en clase agregando los siguientes campos:

- Ciudad
- Año de nacimiento
- Género musical favorito
- Número de canciones favoritas
- Número de playlists creadas

Luego muestra toda la información de forma organizada en consola.

No utilices todavía:

- operadores
- `if`
- ciclos
