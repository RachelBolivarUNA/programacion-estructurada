# Chapter 01

## Thinking Like a Software Engineer

Este capítulo introduce la forma de pensar de una ingeniera o ingeniero de software.

El enfoque estuvo en **pensamiento computacional** y en la **metodología de ingeniería de software**: entender el problema, descomponerlo, diseñar una solución y comunicarla con claridad antes de escribir código.

Durante este capítulo **no se escribió código**.

El objetivo fue construir una base sólida para programar con intención a lo largo del semestre.
