## Cómo usar este repositorio

1. Navega al capítulo que estés estudiando.
2. Lee el `README.md` del capítulo para entender los temas.
3. Abre cada archivo `.cpp`, léelo con calma y compílalo por separado.
4. Experimenta: cambia valores, vuelve a compilar y observa qué ocurre.

### Compilar un ejemplo

```bash
g++ -o demo demo-00-welcome.cpp
./demo
```
